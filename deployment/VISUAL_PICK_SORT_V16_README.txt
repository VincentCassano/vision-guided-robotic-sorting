为什么高度没自动更新：
v15使用RGB视线与同高任务平面的交点，高度由原槽内平面约束。XY不是固定槽坐标，但这属于2.5D。
手眼矩阵只负责相机三维点到机器人坐标的变换；当前三维测高链路未取得最终验收，不能宣称任意高度可抓。
v16是两支撑面的过渡修正，仍须人工选槽内/板顶，不是自动判断任意高度。
板顶模式把目标顶面约束平面沿World+Z移9.6mm，再对每帧当前视线重新求交，重算XYZ；不只是给旧TCP的Z加9.6，也不查槽表。
