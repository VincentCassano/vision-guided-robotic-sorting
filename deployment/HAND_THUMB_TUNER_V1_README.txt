手动对掌与五指调试 v1

仅调手，不连接机械臂SDK、不查询臂位、不发臂动作或Stop。先关闭其他手部控制程序；手内无物、六路活动范围清空后启动。启动只读，不会自动对掌、恢复旧手型或发送PREPARE。

p          拇指对掌到64556（项目历史候选，可用o自行修改，不是厂家默认或已验收握持）
a/b/c/d/e  选择拇指弯曲/食指/中指/无名指/小拇指
o          选择拇指对掌
18000      当前所选通道设为18000
d 18000    无名指设为18000，也可写d=18000
d +500     无名指从刚读到的实际位置增加500
d -500     无名指从刚读到的实际位置减少500
o -500     对掌从刚读到的实际位置减少500
回车       刷新当前读数
r          重新连接并读取；不重发任何旧目标
x          保存手型，仍留在调试界面
q          保存会话后退出；只关闭连接，不发送张开、停止或复位

所有通道都使用0..65535；任意整数目标或步幅由操作者输入，超界按端点限幅。负的绝对目标可写d=-100，结果为0。数值是位置计数，不是角度、夹持力或质量。字母本身只选择，不暗中增加固定步幅。

堵转5、未到位、输入错误不退出、不跳阶段。每次人工目标只发一次并等ACK，不等待实际到位；下一条仍由你决定。拖动机械臂不作为本工具的退出或拒绝条件；本工具不控制臂，示教器仍遵守其自身规则。不要同时使用另一个手部控制程序。观察和调腕时别输入手指目标；只在停稳并撤手后调指。

真实保护3/4不改成普通堵转：该通道仍可下发更小的退让目标，其他正常通道可继续调整。实际过流、身份/配置不符或通信失败暂停写入但保留界面，r新读后再决定。不会清保护、提高限流、修改PID/堵转参数或反复重发不确定指令。通信关闭和程序退出不证明电机已停止；意外接触/运动使用现场硬件停止。

每次写前重新读取手部，保留原始收发。x将记录保存在captures/hand_thumb_tuner_*/hand_shape_NNN.json；有效新读同时更新calibration/hand_thumb_tuning_latest.json。故障后的旧值标为旧读数，不能覆盖当前手型。手型保存不代表实际夹稳、腕姿记录、自动运动基准或视觉抓取验收。
