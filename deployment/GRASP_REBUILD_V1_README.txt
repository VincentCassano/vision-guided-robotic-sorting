先退出旧程序，只运行本入口。仅用同一断电空壳；现场守急停。

1. 空手放在无障碍开始位置，退出示教、停稳。输入 s 记录开始臂位和开始手型。
2. 记录抓取手势：a拇指、b食指、c中指、d无名指、e小拇指、o对掌。
   如 a 40000 是绝对目标，d +500 是增加500，d -500 是回退500。
   六路都允许0..65535，超出自动按边界算；不是角度或夹持力。
   调好输入 x：保存抓取目标，关闭手连接并进入下一步。
3. 同样调成预抓取手势，输入 x 保存。本轮数字完全由你决定，不自动套旧配方。
4. SDK已关闭。保持预抓手型，用示教器摆好围住原位空壳的抓前腕姿。
   空壳落底承托，退出示教并停稳，输入 r 记录腕姿。
5. 确认World竖直上升180mm以及整手扫掠范围无障碍，输入 t。
   按本轮抓取目标闭指后立即自动上升180mm，中途不等键盘。
   目标相同的通道保持；变化通道按对掌→小→无名→拇→食→中发送。
   普通状态5、实际手指未到目标不当作失败；不等待实际到位。
6. 看到空壳确实夹起且稳定：输入 y，保存成功并结束。此时仍持物，不自动松开。
   没夹起：只有手为空、空壳仍由原位置承托、回程和调指扫掠范围均清空时输入 n。
   程序恢复预抓目标→自动MoveJ回记录的开始关节位置→恢复开始手型，然后重新走1～5。
   若仍夹着/悬着或状态不清，不输入 n；q保持退出，先现场处理。

任一步 q 保持退出；调指阶段 q 只取消该阶段，主界面仍保留；r重新读手连接，不重发旧指令。
示教只在主界面等待时进行；调指/读数/自动动作期间不要手动移臂。
