适用现场
仅当前量过的45.8mm×98mm黑色断电空壳，直立、完整等高凹槽落底。
从215223采图到运行期间：目标空壳、工作板、头部相机、底座/升降和手安装均不变。
臂和手可以在两次任务之间变姿；启动重新读当前实际状态，不继承历史当前位、净空或故障末态。
手必须空且悬空，退出示教，关闭其他控制程序；全程独占并现场守硬件急停。
若目标/板/头发生变化，原目标失效，应使用v4取得当前实际目标包，不把旧坐标当新位置。

动作与输入（均按回车）
1. 程序先只读当前身份/DH、SDK、帧、限位、运行模式、保护、整手配置和静止读数。
   当前TCP须已在目标TCP上方至少300mm；本目标要求当前TCP Z>=36.075mm。
   这只是限定启动高度，不证明整手/相机/线缆净空；低位直接拒绝，不自动回臂。
2. 打印当前坐标、高位目标、140mm悬停目标后，m才授权下面三项：
   - 空手一次PREPARE=[8000,8000,8000,8000,65535,65056]，实际到位才推进；
   - MoveJ-P 5%到视觉目标上方高位（Z取当前高度与目标+300mm的较大值）；
   - MoveL 2%固定X/Y与腕姿下降至目标+140mm悬停。
   高位MoveJ-P同时调整腕姿，控制器关节插补中间路径未几何认证。
   m前必须能在现场确认整臂/手/相机/线缆的全段范围无遮挡；不能确认就q。
3. 到悬停点后现场看实际对齐，d才允许MoveL 2%沿World-Z下降到新目标非接触预抓位。
   电池应进入拇指与四指的夹持空隙，各处仍未接触；不要求电池与手之间留14mm。
   140mm是TCP位移，不是已测整手净空。若偏位、不能确认终点不接触或已接触就q。
   等待输入期间不得手动拖臂，当前位变化即退出，重新启动取新当前读数。
4. 终点反馈通过后关闭SDK，保持PREPARE。p/n/u仅记录实际对齐/不通过/未确认，不发命令。
   p要求电池在夹持空隙中且整手未碰电池/板/其他物体；不是抓住或完成分拣。

保护与通信
本机RM65-BI左臂169.254.128.18；SDK API4.3.1、aarch64原库SHA固定。
新鲜World/Arm_Tip零偏移、DH/完整手配置须匹配原成功来源；碰撞等级8、自碰撞True，仅回读，无设置。
普通/驱动关节余量均>=3°；静止前后漂移门0.08°/0.5mm/0.005rad。
静止相邻读数0.02°/0.2mm/0.002rad；终点0.5mm/0.005rad，至少3组跨1秒。
MoveL走廊固定XY<=1mm、腕姿<=0.005rad；每段150秒超时，不重发运动或准备目标。
手位置容差150、目标回读2；实际电流不超过实读1299mA，速度65535、force目标0。
状态3/4或新身份/诊断事件阻断；已存在的诊断1不凭空置零，先核对工作寄存器可读。
状态5如实记录，不代表已停止；相应通道不追加闭合。本入口没有夹持指令。
手部正常断开用disarm而非错误锁存；真正错误锁存保留，不重开写权限。
读取原始碰撞保护和末端参数时手TCP关闭，避免过去的回复串扰。
手TCP在运动中只读；仅分流当前已ACK运动段的一条严格四字段到位通知，不能代替手回复/终点。
未知/重复/失败报文仍拒绝；保持原300ms事务间隔、原始字节及同长度身份栅栏。

停止与结果
意外接触、非受控继续运动立即现场硬件停止，不等待程序。
故障如本轮已发臂运动，至多尝试一次Move_Stop；其ACK或程序退出不证明物理停止/卸扭矩。
没有自动张开、下降恢复、回臂、闭指、带载提离或投放。
每次均保存captures/visual_pregrasp_alignment_*.zip，含父/子结果、当前状态、手报文、SDK调用、许可与哈希。
结束统一回传一个ZIP；失败也保留原始结果，不用故障last_arm_state替代新的启动资格。
