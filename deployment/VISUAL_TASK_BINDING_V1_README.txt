视觉目标到固定腕姿预抓TCP的一点任务绑定 v1（2026-10-20）

目的：接通“图像里空壳的连续位置”与“机械臂真正使用的预抓TCP坐标”，不是再次检查116mm槽距，也不是重采手眼。现有视觉几何中心不能直接作为Arm_Tip。只用一次现场配对确定固定腕姿的位置对应，以后按新目标的实际视觉位移连续计算新预抓坐标，不按槽号查表或吸附坐标。

为什么需要这一次现场图像：过去没有与真实落槽预抓点成对保存该空壳的RGB几何参考，不能从旧日志杜撰。最后123051夹稳前已经部分提离/倾斜，那个TCP比早先落槽预抓高约11mm，绝不能和重新落底的图像配对。本包位置基准取024412已完成下降的真实非接触端点，并与081023的qualified_reference完整核对；123051只提供最后夹稳配方和已接受反馈，不用故障last_arm_state，也不把140mm未确认终点当参考。

本次范围：实时相机采图、一次绑定、连续新目标的预抓TCP候选输出。没有SDK导入、臂连接、臂/手/配置写入；不下降/夹持/回臂。相机启动RGB1280×720/30fps，不启动深度、不写相机选项。已有YOLOv3模型、阈值、几何算法和标定候选不变。新位置的实际预抓对齐、下降/夹取及整轮视觉投放仍待真机，不把候选或一点绑定冒充六维TCP/绝对5mm/通用手眼通过。

现场一次操作：
1. 从框内取出同一只量过的黑色空壳（直径45.8mm、高98mm），放回先前手动摆预抓并成功夹起的原完整凹槽，保持原来槽内位置、完全落底且直立。不是随便选另一个槽；记不清原位就不要猜，不能用任意图像配旧点。头部相机、机器人底座/升降、工作板及灵巧手安装均须保持原关系；机械臂当前姿态可以变化，可以留在刚才空返高位。
2. 窗口只保留这一只实测空壳；无遮挡地看见外顶圈和侧面。若空手挡住目标，可用已有控制把空手移出视野，不动头/板/底座。该程序不占用或查询机械臂SDK。按编号或点击真实空壳选中。
3. 原槽按S一次，保持空壳静止。连续至少8帧/约2秒、全部合格且抖动≤原3mm后，终端和画面显示REFERENCE BOUND。失败保留具体原因和原图，不消耗绑定资格，不要求重采16组或再做A/B。
4. 看到REFERENCE BOUND后，再把同一空壳放到你接下来想抓的新位置，稳定直立且有完整支撑，撤手、重新选中。窗口实时显示TASK PREGRASP TCP mm，表示新目标对应的末端预抓候选。新位置按S一次保存；不要求移动116mm或必须指定槽。需要更多新目标可以继续选/S，最后Q统一打包，一次回传。
5. 结果为captures/visual_task_binding_时间.zip；task_anchor.json保存绑定，latest_target.json/target_001.json等保存新目标。程序退出后会直接打印下次复用绑定的完整命令，无须重新放回原槽配对。复用时保持原参考JSON/PNG与task_anchor.json一起，不单独搬一个JSON。

计算与接口：
新预抓TCP位置 = 原已接受落槽预抓TCP位置 +（新空壳顶中心World位置 - 参考空壳顶中心World位置）。
固定RPY保持原已接受落槽预抓值。XYZ内部单位m、腕姿rad；屏幕与*_mm字段只用于显示mm。不按电池轴线解算新腕姿，不做尺寸缩放或槽位吸附。手臂当前姿态没有参与绑定值，之后实际控制仍必须新鲜读取当前状态。

target文件还给出上方140mm的悬停候选，只是接口数据，绝不是整手最低点净空或可达性/扫掠证书。execution_ready和motion_authorized始终false；后续控制器要先完成新位置的实物对齐/可达性/路径和当前臂手资格，不能只读XYZ发下降。

绑定的复用边界：固定相机/工作板/底座/手安装、相同实测空壳和固定任务腕姿；只允许机械臂自身当前姿态变化。其他尺寸/颜色/物体、相机或头部偏移、安装变化、任意腕姿均不在该绑定内。原相对距离通过、六组标记PnP一致性与真实物体绝对精度分别保留；原RGBD/六维角度失败不改写。本包保留原8帧/2秒/3mm、6点PnP5mm与图像算法门，没有把它们降低后开放动作。
