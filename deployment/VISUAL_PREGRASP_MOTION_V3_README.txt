视觉实时目标→实际高位对准→下降 v3（2026-10-21）

本次是实际动作入口，不再运行负载辨识或要求称重/技术支持。
现有工具负载只读取、记录并在本轮锁定，不写入、不取平均，不声称其物理值已验证。
旧的v2 pending资格文件不是本入口的依赖。旧入口和已发布ZIP不修改。
这次推进到视觉新位置的非接触预抓；夹持、提起、投放和返回尚未接入本入口，不冒充完整分拣通过。

执行前
1. 退出当前辨识页，不点击添加新候选，不改现有工具/负载。
2. 示教器中确认碰撞保护等级8、自碰撞检测开启；如果目前是0，只恢复这两项既定保护。
   程序自己只读保护，不清错、不修改保护或工具配置。仍有控制器故障时不能运行运动。
3. 空手悬空，退出示教/轨迹播放，关闭其他控制脚本；全程独占并现场守硬件急停。
4. 保留同一45.8mm×98mm黑色空壳，直立且在同高完整槽完全落底。
   头部相机、底座/升降、手安装、工作板相对底座的位置和高度须与原视觉绑定一致。
   允许机械臂在任务间变姿；本次现场读当前位，不回旧姿态。若相机或板已移动，不冒用旧外参。

现场操作
1. 打开的v4视觉窗口点真实空壳，按S。出现PLANE TARGET SAVED（saved targets至少1）后按Q。
   使用本次创建的唯一目标包；无合格目标则退出，不会拿旧目标替代。
   不用挪回原槽、不重绑参考、不重采16组；相机关闭后才连接臂手。
2. 程序读取当前设备身份、DH、安装、工具/工作坐标、限位、保护和手部配置。
   输出当前TCP、原位升高目标、高位目标、140mm悬停目标和当前工具原始配置。
   不需要再回传这一轮读取才能继续。现有负载未知如实记录，不作为物理资格通过。
3. 现场确认整臂、手、相机和线缆：准备手型范围、原位升高、向目标对准和下降通道均无遮挡。
   高位关节插补会改变腕姿，途中扫掠未经几何认证；不能确认就q。
   输入m并回车：一次PREPARE→必要时按当前腕姿原位竖直MoveL 2%升高→MoveJ-P 5%高位对准→MoveL 2%下降至目标上方140mm。
   原位升高只改变World-Z，不横移、不自动回历史点；升至max(当前Z,目标Z+300mm)。
   当前TCP低于目标TCP+140mm则拒绝，不做低位自动恢复。
4. 到140mm悬停点后看实际对齐，确认最终下降终点无接触再输入d并回车。
   d只授权固定腕姿沿World-Z降到视觉非接触预抓点；偏位/接触/不确定就q。
   140/300mm均为TCP位置差，不是整手或带载净空；不要求电池和手留14mm。
5. 终点关闭SDK、保持PREPARE，p/n/u记录实际对齐/未对齐/未确认。
   p不是抓住或完成分拣。captures/visual_pregrasp_alignment_v3_*.zip为统一回传结果。
   本次视觉原图和目标包原样放入动作结果input_visual_target.zip并记录SHA256，只回传最终动作ZIP即可。

保持的限制
当前原始工具/工作几何必须为零法兰/World；工具名称和负载按本轮实际读数锁定，不要求历史零负载、不指导切换回零。
完整SDK帧在本轮首次读后逐次精确匹配；每段再从原始GET核对工具、工作帧和安装信息。
SDK/原始质量单位核对，SDK质心单位不在本次解释或应用，仅保留原值并锁定；不据此认定参数正确。
当前错误非0、保护非8/True、配置变化、手状态3/4、过流或漂移均阻断；不得关闭保护让程序通过。
关节余量3°、漂移0.08°/0.5mm/0.005rad、竖直XY走廊1mm及原手部限流/配置门保持。
同高平面定位是当前限定2.5D任务，不等于通用六维标定、任意高度或多类别分拣已通过。
未知负载与未验证扫掠仍是运动限制；本次受现场监督的空手动作不提供碰撞停止保证。
意外接触或非受控运动立即现场硬件停止。软件Stop ACK/退出不等于物理停止或卸扭矩。
故障至多尝试一次臂Stop，不重发运动、不自动张开、清错或回臂；无名指持续堵转等既有问题不改判。

交付核对仅源码阅读和文件/ZIP/哈希；没有运行项目测试、AST/compile/mock、FK/IK、图像拟合、SDK或设备动作。
