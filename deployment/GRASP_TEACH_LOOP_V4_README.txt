五指自定义目标调节 v4

a拇指 b食指 c中指 d无名指 e小拇指。
输入 d 18000：无名指目标设为18000。
输入 d：只选择无名指，不动作；随后输入18000同样设置它。
任何整数均为绝对目标，不是角度或增量；d +3000也表示目标3000，不是再加3000。
负数按0，超过该指上限按上限；没有固定250/1000步长限制。
当前开发候选上限：30000 / 31500 / 29500 / 20250 / 65535。这不是厂家安全持力认证，也不代表机械指节角度。
x完成当前阶段；q保持退出；?才显示帮助。等待“执行中”结束再输入下一目标。支持通常终端编辑/历史；无readline环境仍可直接输入，不增装依赖。

流程：空手、手势活动范围清空、退出示教停稳后s开始预抓调指；x后SDK退出，用示教器调腕；退出示教停稳s开始夹持调指；x后SDK退出，示教器低速向上试提；y实物离槽且无托举夹稳，停止记录；n失败先让空壳完全由板承托、清空五指活动范围，b张开并恢复本次预抓，再回调腕。

启动保留当前手型，不发旧配方。不自动移臂/提起/分拣、不动对掌、不改保护或清错。只用同一断电空壳，退出其他控制，现场守急停。SDK连接期间禁止拖臂；实际未收到退出确认不能示教。脚本退出不证明物理停止；意外接触、失控运动或明显升温现场硬件停止。

实际仍受阻的手指不能直接强加闭；设置比其当前实际位置更小的目标才能退开。空手退行>=250、目标到位150内、3组状态2静稳>=1秒才重新合格。正常命令内部短暂5，但最终3组静稳状态2且到目标，不再永久记作故障；仍保留完整原始状态。真实3/4、过流、身份/配置/通信/限位/臂漂移异常仍终止，无自动重试或强制清除。
