3. 将空壳放到这轮想抓的位置，同高落底；输入 s，窗口点选它、按S保存。

4. 输入 g 授权整轮：
   读取当前健康空手臂位→MoveJ到本次实测高位→恢复新预抓手型→按当前视觉坐标高位对准

5. 投放后 y=确实夹起且投入黑框/手空；f=漏抓或未入框但手空；q=仍持物或不确定。
   可以换位置继续s/g，多轮结束q统一一个ZIP。程序停在投放点，不自动假定已经空返。
