v18：五指实际位置自动判断；直立圆柱约束测高。

操作：
1. 旧相机窗口Q、旧主界面q退出。保持头部、板、安装及现有绑定不变。
2. 启动v18，直接s，点当前空壳并按S；不需要e，不选择槽内/板顶，不重做b。
3. 采样合格后g，执行对准→下降到位→整组预抓→整组夹持→提180mm→转运→整组松开。
4. g/p会自动读取五指实际位置；需要张开时先原地OPEN5，读到实际张开再移臂。五指已张开则跳过写入，对掌保持。
5. y/f只记实际取放结果，不再充当“空手许可”。下一轮直接s。p回实测高位，q保存退出。

g/p适用于同一断电黑色空壳，同时授权当前原地张开；张开扫掠、空壳可能落下的区域及整条运动路线须清空，退出其他控制并守现场急停。
五指目标0±2、实际位置≤150原始计数，沿用现有寄存器回读/到位容差；不检查对掌是否为0。
这是“已张开”的判断，不是物体检测或“无物”的证明。实际张开未确认时不先移动；主界面保留。
