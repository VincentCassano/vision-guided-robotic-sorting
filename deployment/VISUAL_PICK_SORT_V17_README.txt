v17：统一s选目标，程序自动判断当前板的支撑高度。

不再让人选择槽内/板顶，不需要输入t，也不重新绑定成功腕姿。
本次改动尚未真机验收；没有执行项目、编译、AST、离线测试、图像重放、FK/IK或SDK。

操作：
1. 退出旧入口，启动v17。手已经为空时e回车。
2. 若仍由板面承托、手夹着：臂静止且松指范围清空时o回车，只松五指、不移臂；实际手空后e。
3. 统一s回车，相机中点击当前空壳并按S。程序自动判断高度，画面会显示AUTO RECESS或AUTO BOARD_TOP。
4. 保存合格目标后回终端g回车，执行对准→下降→预抓→夹持→提180mm→转运→五指整组松开。
5. 实际夹起入黑框且手空后y；漏抓但手空f；仍持物或不确定q。下一轮仍然s，不分位置类型。
6. 最后q保存一个完整结果ZIP。p仅空手回观察高位，b只在原绑定确实失效时使用。

若显示AUTO HEIGHT UNKNOWN，程序保存原图和原因，不生成运动坐标、不默认按槽内高度；界面仍可继续使用。
相机估测失败不要求人选择高度，原目标也不会作为补位继续运动。

自动判断范围：
同一45.8×98mm直立断电黑壳、当前亚克力板、头部/板/安装不变。
板顶比槽底高9.6mm是已经测过的场景几何，程序自动判断物体属于哪个支撑面；XY仍从实时图像连续求出，不查槽号或固定抓取点表。
这是自动辨别本板两个已知支撑面，不等同任意未知高度/任意姿态的完整三维定位，后者仍未完成。

如何判断与记录：
- 使用现有已知尺寸圆柱RGB几何的原始三维观测，计算各帧相对原参考面的高度；不增加深度流、不更改相机选项。
- 至少8帧/2秒，全部原始帧保留；高度最大波动仍为3mm，所有帧必须支持同一个高度类别，估测不确定区不能跨越两层中点。
- 最近支撑面的高度残差必须小于两层实测间距的一半，即4.8mm。这是可区分性条件，不是绝对精度证书；不通过就不猜。
- 自动选定平面后，为每一帧重新计算视线交点XYZ，仍保留原2px图像门、原3mm位置波动门。
- 原自由三维成功/失败另存，不能因高度分类通过就改写原三维失败。原始帧、自动判断证据、逐帧投票和最终平面均保存。
- 动作进程重新核对自动判别及候选来源，不能手改一个surface字段就发动作。

复用成功手型、下降后PRE6、GRIP3、180mm提起、三段1/1/0投放及OPEN5；普通状态5继续允许，真实3/4、过流和通信/臂保护检查保留。
g/p仍须现场确认当前整段臂手/相机/线缆/持物扫掠清空、预计净空≥20mm，退出其他控制并守急停。
v16原文件和包保留作为历史；当前使用v17单入口，已有calibration/visual_pick_sort_v14_anchor.json不覆盖。
